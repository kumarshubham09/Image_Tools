# Pixel & Vector 🎨

A premium, browser-based image toolkit for designers and professionals. This project includes a modern **Image Converter** (WebP/SVG) and a **Passport Photo Maker**.

## Features

- **Modern Converter**: Convert PNG/JPG to high-quality WebP or traced SVG vectors.
- **Passport Pro**: Crop and generate printable passport photo sheets (4x6 inch) with standard country sizes.
- **Privacy First**: All processing happens locally in your browser. No images are uploaded to any server.
- **Premium UI**: Dark mode, glassmorphism aesthetics, and smooth animations.

## How to Test Locally

1. Clone the repository.
2. Run `npm install` (optional, for dev tools).
3. Run `npm start` to launch the local server.
4. Open `http://localhost:8080` in your browser.

## Deployment Instructions

To share this tool with others, you can deploy it for free using one of these services:

### Option 1: Netlify (Recommended)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop this folder onto the page.
3. You will get a live link instantly!

### Option 2: Vercel
1. Install Vercel CLI: `npm install -g vercel`.
2. Run `vercel` in this directory.
3. Follow the prompts to deploy.

### Option 3: GitHub Pages
1. Push this code to a GitHub repository.
2. Go to **Settings > Pages**.
3. Select the `main` branch as the source and click **Save**.
